## Key decisions made
- **One PR for the whole session migration** (code + docs) rather than
  splitting them: the documentation describes the state of the code, and
  keeping them atomic avoids `main` ever documenting a Redis architecture
  that no longer exists.
- **8-hour application session timeout.** Weighed explicitly against a
  30-minute posture: Pecunia is a daily-use personal tool on a personal
  device and the cookie is `HttpOnly`. Recorded as worth revisiting when
  the production instance goes public with the `demo` user.
- **Historical ADRs (0006, 0011, 0020, 0021, 0022) are not rewritten**
  even though they still mention Redis: an ADR records a past decision,
  and ADR-0038 supersedes them. Same reasoning for the Block 1 deliverables
  in the roadmap, which describe what was actually shipped then.
- **Keep both the screenshot and the live calculator link** in ADR-0035.
  The link restores the *configuration* but renders the tariffs of the day
  it is opened, so only the dated screenshot evidences the price at
  decision time.
- **Smoke test scope**: `ClientRegistrationRepository` is the only bean
  replaced (the real one performs OIDC discovery at instantiation and
  would require a running Keycloak; the flow is already covered by
  Playwright), and the test runs with `RANDOM_PORT` rather than `MOCK`.

## Concepts explained / learned
- **Two sessions, not one.** A login creates an application session
  (`SPRING_SESSION` in PostgreSQL, `SESSION` cookie on the backend origin)
  and a Keycloak SSO session (`KEYCLOAK_IDENTITY` on the Keycloak origin).
  Crucially, **browsing Pecunia does not refresh the Keycloak session** —
  the two clocks run independently.
- **The four durations**: application session idle (8 h, the only one that
  matters today), Keycloak SSO idle (30 min, useless with a single client
  in the realm), SSO max (10 h ceiling), access token lifespan (15 min,
  dormant because no outbound call is made on the user's behalf).
- **`SameSite=Strict` would break OIDC login**: the cookie would be
  withheld on the cross-site redirect back from Keycloak. `Lax` is the
  correct value for a BFF, not a weaker compromise.
- **Spring Session's cleanup needs no application wiring**:
  `JdbcIndexedSessionRepository` creates its own `ThreadPoolTaskScheduler`
  in `afterPropertiesSet()` and schedules the cleanup with a `CronTrigger`
  — verified in the bytecode, then observed at runtime as thread
  `spring-session-1`.
- **`perf1` vs `perf2`** (Infomaniak): 500 IOPS / 200 MB/s versus
  1000 / 400, and perf2 is **enabled on request only** — so perf1 is the
  correct default rather than merely the cheaper one.

## Issues encountered & resolved
- **The module had no `@SpringBootTest` at all.** Both session migrations
  could only be validated by hand: `mvn verify` would have stayed green
  with the session wiring broken. Closed by `ApplicationContextSmokeTest`.
- **Smoke test first reported 30 minutes instead of 8 hours.** In
  `webEnvironment = MOCK` there is no servlet container, so
  `ServerProperties` is never bound and Spring Session falls back to its
  own default. Fixed with `RANDOM_PORT`, which also makes the test more
  faithful (the filter chain is built for real).
- **`getDefaultMaxInactiveInterval()` does not exist** on
  `JdbcIndexedSessionRepository` (only the setter). Asserted through
  `createSession().getMaxInactiveInterval()` instead — a better test
  anyway, since it checks observable behaviour rather than a field.
- **Infomaniak tariff pages and calculator are JS-rendered** and unreadable
  by fetch (same blocker as Session 34). Worked around by reconstructing
  the price from component rates (instance `disk0` + storage per GB/h),
  self-checked against the perf2 variant to 0.4 %. The estimate
  (CHF 16.13) landed within 0.25 % of the official CHF 16.09.
- **The July price estimate was low by ~50 %** (~€14.50 → CHF 19.43),
  almost entirely because of the reserved IPv4 that no aggregator listed.
  The decision is unaffected: the comparison was against Exoscale (~$67)
  and Azure (~$45–60), and the figure stays inside the CHF 10–20 target.
