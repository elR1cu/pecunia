## Key decisions made

- **Frontend authorship delegated to Claude**: the user's priority is now
  reaching deployment; the mentor-charter division (user writes applicative
  code) is consciously suspended for the frontend.
- **Identity via token overrides, not a custom Material palette**: a handful
  of `--mat-sys-*` overrides after `mat.theme()` restyles every component
  coherently without maintaining a generated palette.
- **Fraunces (brand) + Inter (plain) through the M3 typography roles**, so
  headline/display styles pick the serif automatically.
- **Signature element**: the accounting double rule — subject-true, cheap,
  reused (page titles, landing ledger total) instead of scattered effects.
- **Outlined form fields globally** via `MAT_FORM_FIELD_DEFAULT_OPTIONS`
  rather than per-field attributes.
- **Mobile nav = hamburger + `MatSidenav` drawer**; the first attempt
  (scrollable inline nav with hidden scrollbar) was undiscoverable and
  truncated — replaced with the standard pattern.
- **`CategoriesState` refetches after every mutation** instead of patching
  the tree locally: the nested shape makes server truth cheaper and safer.
- **Stacked-branch workflow**: e2e fixes were committed on the branch that
  owns their cause (nesting fix → category branch; outline workaround →
  redesign branch), with rebases (`--onto main`) re-signing replayed
  commits automatically.
- **Sonar issues**: real a11y fix *and* documented false-positive ignore,
  rather than either alone.

## Concepts explained / learned

- **Playwright `has:` semantics**: the inner locator is evaluated relative
  to each candidate element; passing a locator that carries its own parent
  chain silently matches nothing.
- **Playwright actionability vs. Material outline notch**: the floating
  `<mat-label>` can sit over a select's click point; a real user is fine
  (the form field forwards clicks) but Playwright refuses intercepted
  clicks — click the `mat-form-field` instead.
- **Angular emulated encapsulation & the router**: router-created components
  carry `_nghost` but not the shell's `_ngcontent` attribute, so scoped
  child selectors (`main > *`) cannot reach them — each page must style its
  own `:host`.
- **Coverage plumbing**: Angular's Vitest LCOV instruments HTML templates,
  but the Sonar gate ultimately counts TS lines/conditions; the decisive
  gaps were an uncalled helper and a predicate never run on non-empty data.
- **Node `require(esm)`**: `openapi-generator-cli` requires the ESM-only
  `proxy-agent` 8; this works from Node 22.12+/24 and breaks on 22.9 —
  the `.nvmrc` (24.16.0) is authoritative, `nvm use` before frontend work.
- **`WITH RECURSIVE`-style recursion in templates**: a standalone
  component's own selector is implicitly available in its template.
