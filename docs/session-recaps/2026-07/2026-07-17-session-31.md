## Key decisions made

- **CTE uses `UNION`, not `UNION ALL`**: the query is itself the cycle guard,
  so deduplication guarantees termination even on corrupted cyclic data.
- **Hybrid endpoint split** (after researching Geewax's *API Design Patterns*,
  Google AIPs, Zalando): ordinary field edits via `PATCH`; re-parenting via a
  `POST /{id}:move`-style custom method (AIP-136); archive via soft-delete
  `DELETE` (AIP-164). Standard `Update` must not carry state/structural
  transitions.
- **GitHub-style partial update instead of RFC 7396 merge-patch**: the stack
  generates with Jackson 3, and `JsonNullable` (the only absent-vs-null
  discriminator) is a Jackson 2 module — so true merge-patch null semantics
  are unavailable. `icon: ""` clears; `newParentId` null-or-omitted detaches.
- **ADR-0034 status doctrine, applied transversally**: migrated `account`
  immediately rather than scoping 422 to `category`, to avoid shipping an
  internally inconsistent public contract.
- **`CategoryCannotBeItsOwnParentException` → 409**: mapped defensively even
  though the move service rejects a self-parent as a `CategoryCycleException`
  first (so it is currently unreachable).
- **`CategoryNodeResponse` drops `parentId`**: mirrors the `CategoryNode` read
  model, which omits the parent link because the tree nesting encodes it.
- **Response DTOs named `CategoryResponse` / `CategoryNodeResponse`**: to
  differentiate from the application-layer `CategoryView` / `CategoryNode`
  read models (user's call).

## Concepts explained / learned

- **`WITH RECURSIVE` execution model**: iteration over a working table (anchor
  seeds it; the recursive member joins only against the previous iteration's
  rows), not function-style recursion; terminates when an iteration adds no
  new rows — hence `UNION` breaks cycles.
- **400 vs 422 vs 404 for bad body references**: RFC 9110 + GitHub converge on
  422 (well-formed but unprocessable); 404 is bound to the URL's resource, not
  a referenced one. Cross-tenant indistinguishability extends to references.
- **`@ExceptionHandler` precedence**: Spring resolves the most specific type,
  so explicit 409 handlers on `DomainException` subtypes win over a generic
  `DomainException` → 422 handler.
- **MapStruct division of labour** (from `AccountMapper`): inbound DTO→record
  is annotation-driven with `@Named` helpers where value objects / `Optional`
  must be built; outbound read-model→DTO is a hand-written `default` builder
  chain because every field needs unwrapping.

## Issues encountered & resolved

- **`openApiNullable` challenged by the user**: the earlier "verify it for
  `icon`" note conflicted with the pom's `openApiNullable=false`. Root cause:
  `JsonNullable` is Jackson 2 only, incompatible with the stack's Jackson 3 —
  self-corrected, pivoted to the GitHub-style update pattern.
- **Response-schema rename fallout**: renaming `CategoryView`→`CategoryResponse`
  and `CategoryNode`→`CategoryNodeResponse` broke the controller's imports and
  signatures (regenerated `CategoryApi` changed); fixed the pom `models` list
  and regenerated.
- **`cd` changing the persistent Bash working dir**: a compound `cd` left later
  `find`/`grep` calls failing; switched to absolute paths.
